# Project Status and Obtaining Items

Furniture Plan is an alpha furniture mod with large sets of seating, surfaces, decorations, and storage furniture based on vanilla materials, plus several tableware and lighting items.

## Installation Scope

- The target is Minecraft 26.1.2 with NeoForge 26.1.2.30-beta.
- Furniture blocks and interactions are common content, so Furniture Plan should be installed on both client and server in multiplayer.
- Ageratum is only a client-side documentation reader and does not participate in furniture saves or server gameplay.

## Obtaining Items

There are currently no furniture crafting recipes. Use the five Furniture Plan Creative tabs or `/give`. The tabs are Miscellaneous, Sitting, Surfacing, Decorating, and Storage.

The guidebook item ID is `furnitureplan:ageratum_guidebook`. When Ageratum is installed, it appears in the Miscellaneous tab and opens this documentation on use.
