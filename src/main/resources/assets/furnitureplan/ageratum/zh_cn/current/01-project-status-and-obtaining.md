# 项目现状与获取方式

家具计划是一个 Alpha 阶段的家具模组，当前提供大量按原版材料生成的座具、台架、装饰和储物家具，以及少量餐具与灯具。

## 安装边界

- 模组目标版本是 Minecraft 26.1.2 与 NeoForge 26.1.2.30-beta。
- 家具方块与交互逻辑属于公共内容，联机时客户端和服务端都应安装家具计划。
- Ageratum 只是客户端文档阅读器，不参与家具存档和服务端玩法。

## 获取方式

当前没有家具合成配方。请从家具计划的五个创造模式分页获取内容，或使用 `/give` 命令。分页分别为杂项、可乘坐类、置具台类、装饰类和存储类。

指南书物品 ID 是 `furnitureplan:ageratum_guidebook`。安装 Ageratum 后，它会出现在杂项分页；右键会打开本文档。
