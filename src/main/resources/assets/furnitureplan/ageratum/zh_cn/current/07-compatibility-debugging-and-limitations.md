# 兼容、调试与已知限制

## 已知限制

- 当前没有生存配方，也没有已注册的雕刻刀物品。
- 火炉、饮水机和独立水瓶目前注册为普通占位方块，没有预期的加工或供水功能。
- 铁锅和盘子没有燃料、进度或配方处理系统。
- 展示架没有 GUI，必须准确点击展示位。
- 圆月架必须拥有完整 3×3 空间，嵌灯柱不能关闭。
- 当前没有玩家可调配置。

## 排查方法

如果指南书无法打开，先确认客户端已加载 Ageratum，并检查 `/ageratum "furnitureplan" "index"` 是否可执行。若家具交互异常，请确认点击面、潜行状态、手持物品、结构空间和支撑方块符合对应章节要求。

本文档描述当前 Minecraft 26.1.2 工作区，不保证与旧版发布包完全一致。
